The sidebar

One list for every project. This is a working copy; click through it.

Opening it

Press the ☰ ToDo’s N button in the prompt footer (N is this project’s open items), or type /todos. The sidebar opens on this project. If this project has nothing open but others do, it opens on all projects. It lands on the first tab that has items, Agent first.

Scope

The line under the title reads This project. Press it to switch to All projects. Counts on the tabs follow the scope.

Tabs

Tabs split items by who started them, nothing else.

TabHolds
AgentItems Claude recorded, found with the scan, or mirrored from its task lists.
HumanItems you added with /todo add.
DoneFinished and dropped items from both. Newest first.

Groups

Inside Agent and Human, items are grouped by what they need from you, in this order:

GroupKindMeaning
Needs decisionproposalClaude suggested work you did not ask for. Approve or Reject.
To dotodoWork to be done.
DiscussiondiscussionAn open question to talk through.
ParkeddeferredPut off on purpose, with the reason.

Each row shows the title on up to two lines, then the project, the session and the age as small tinted tags. The whole row opens the card. After 40 rows, Show N more reveals the rest.

The card

Opening an item shows its card in place, with an accent border: the title, a short plain-English description of what the work is and why it came up, the latest notes and the actions. Close puts it away. Older notes sit behind Show N earlier.

ActionDoesKey
StartOpens Send, Draft and Copy (or Terminal). See below.s
DoneMarks the item done and moves to the next one.d
DropMoves the item to Done as dropped. Nothing is deleted.x
NoteOpens a box. Type, press Enter.n
ApproveProposals only. Turns the proposal into a to do.a
RejectProposals only. Same as Drop.x

Tabs also answer to 1 2 3, and r reloads the list.

Start options

After Start, one press picks how the task is handed over:

OptionDoesKey
SendSends the prompt to Claude now. If a reply is running, it queues and starts when that reply ends.s
DraftPuts the prompt in your prompt box so you can edit before sending.d
CopyCopies the prompt to the clipboard, for another session. Desktop app.c
TerminalTerminal app. On Windows, opens a new Claude window in the project folder. On macOS and Linux it copies the prompt.t

The prompt looks like this, and ends by asking Claude to mark the item done:

Work on this ledger item (id 20261012-0951-3c1f, deferred, from project billing-api):
Retry failed webhook deliveries
Failed webhook deliveries are dropped today, so a missed payment update never arrives…
Notes:
- human: only retry on 5xx
When finished, call update_item with id 20261012-0951-3c1f and status done.

The Done tab

Open a closed item to Reopen it. Items that were dropped also offer Delete forever, which asks for a second press to confirm. Done items cannot be deleted from the sidebar.
