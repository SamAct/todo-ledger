Commands and tools

Two slash commands for you, four tools for Claude.

Slash commands

CommandDoes
/todosOpens or closes the sidebar.
/todos listPrints this project’s open items in the chat.
/todos list allPrints open items from every project.
/todos refreshReloads items written by other sessions right now.
/todo add <text>Adds a to do.
/todo add -d <text>Adds a parked (deferred) item.
/todo add -p <text>Adds a proposal.
/todo add -n <text>Adds a discussion.
/todo done <id>Marks an item done.
/todo delete <id>Deletes a dropped item for good.

Ids look like 20261012-0951-3c1f. /todos list prints them.

Tools Claude uses

These are registered with Claude Code, so Claude can call them on its own. Their descriptions tell it to keep the list current without being asked.

ToolInputsDoes
park_itemtitle, kind, bodyRecords an item. kind is todo, deferred, proposal or discussion. body is the two to four plain sentences shown on the card.
list_itemsscopeLists open items. scope is project (default) or all.
get_itemidReads one item in full, with its notes. A unique prefix of the id works.
update_itemid, status, title, kind, body, noteChanges an item. status is open, in_progress, done or dropped.

Agents can set an item to dropped, which moves it to Done and can be reopened. They cannot delete. Only you can, from the Done tab or with /todo delete.
