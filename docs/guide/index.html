Get started

Install, open the sidebar, and have a first item in the list in about two minutes.

Install

You need Claude Code 2.1.287 or later (mods support), in the desktop app or the terminal. Run these two commands inside Claude Code:

>/plugin marketplace add SamAct/todo-ledger
>/plugin install todo-ledger@todo-ledger

Then start a new session, or run /reload-plugins. A ToDo’s button appears at the right of the prompt footer.

Updating. Refresh the marketplace and reload: /plugin marketplace update todo-ledger, then /reload-plugins.

Add your first item

Type this in any session:

>/todo add Rotate the staging API key

Press the ToDo’s button, or type /todos. The item is under the Human tab, because you added it. Click it to open its card.

Let Claude add some

You do not have to do anything. Claude is told to record an item whenever it defers, parks or postpones work, or proposes something you did not ask for. Ask it to “fix this and leave the refactor for later” and the refactor shows up under Agent, under Parked, with a short note on what it is and why.

Pick an item back up

Open a card and press Start, then Send. The prompt is written for you: the title, the details, your notes and the project it came from. When Claude finishes, it marks the item done.
