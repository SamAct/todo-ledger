FAQ and troubleshooting

Quick answers, then fixes.

Questions

How is this different from Claude’s own to-do list?

That list is a scratchpad for the task in front of Claude and goes with the session. todo-ledger is permanent, spans every project, and holds what never made it onto a plan: the “we could also…” and the “not now”. It also mirrors those task lists, so unfinished plans are kept.

Does it work in the desktop app and the terminal?

Both, with the same list and files. Start offers Copy in the desktop app and Terminal in the terminal app.

Does it work on macOS and Linux?

Ported and unit-tested, but not yet run on real macOS or Linux machines. Windows is the tested platform. If you try it elsewhere, open an issue either way.

How do I remove it?

/plugin uninstall todo-ledger@todo-ledger. Your items stay in the folder until you delete it.

Is it an official Anthropic project?

No. It is an independent open-source mod by SamAct.

Troubleshooting

The ToDo’s button does not appear

  1. Run claude --version. Mods need 2.1.287 or later. Update Claude Code if it is older, and update the desktop app too.
  2. Start a new session, or run /reload-plugins.
  3. Run /plugin and check that todo-ledger is installed and enabled.

The sidebar is blank, or says it could not draw

Close it and open it again with /todos. If it persists, run /reload-plugins and open an issue with the message shown.

Items from another session do not show up

Sidebars refresh about every ten seconds. Type /todos refresh to reload now.

In the desktop app, the first click does nothing

After typing in the chat, the first click on the sidebar may only move focus into it. Click again. Opening the sidebar on hover is not possible with the current mod API.

I deleted something by mistake

Drop only moves an item to Done, and Reopen restores it. Only Delete forever removes a file, and only for dropped items, after a confirm.
