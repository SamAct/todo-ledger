# Product

## Register

brand

## Users

Developers who use Claude Code daily, in the desktop app or the terminal, across several projects at once. They already trust it with real work. They lose track of what Claude deferred, parked or proposed once a session ends. They install tools from a GitHub README and a short landing page, and they judge a tool by whether the page shows it working.

## Product Purpose

todo-ledger is a Claude Code mod: one global list of the work Claude and the user leave behind, shown in a "ToDo's" sidebar. The site exists to get a developer from "what is this" to "installed" in under a minute, then to answer the docs questions that follow (commands, privacy, how items get in and out). Success is installs and stars from people who read the page and understood the product.

## Brand Personality

Calm, exact, a little dry. A tool that keeps books: nothing lost, nothing loud. Plain English over jargon, specific over adjectives.

## Anti-references

Gradient-text hero with a glowing orb. Three identical icon cards. "Supercharge your workflow" copy. Fake logo walls and invented stats. Stock photography. Neon on black. Anything that looks the same as every other AI-generated SaaS page.

## Design Principles

1. Show the real thing. The hero is a working replica of the sidebar, not a picture of one.
2. One accent, used for what needs the user. Everything else is quiet.
3. Say what it does and what it does not do (privacy, data location, no telemetry) before the reader has to ask.
4. Docs are part of the product: scannable, exact, every command copyable.
5. Independent project: say so, plainly.

## Accessibility & Inclusion

WCAG AA contrast on the dark theme, visible focus rings, full keyboard use of the demo, `prefers-reduced-motion` respected (the demo shows its end state at once), no content that depends on hover.
